# Research

Customer psychology and marketing science research, compressed into
design principles, and diffed against the Agent Runtime System's
existing behavior.

- `Customer_Psychology_Marketing_Research_v1.md` — Phase 1: the full
  7-domain research synthesis, real sourced citations. Kept as the
  primary source for a possible future academic-paper treatment (see
  00_Project_Control/Research_Paper/ for that task's status).
- `customer_psychology_principles_v1.md` — Phase 2: 47 principles
  compressed from Phase 1, confidence-graded.
- `Architecture_Diff_Report_v1.md` — Phase 3: each principle diffed
  against the runtime architecture (confirms/new/flag), with the
  approved amendments that were applied to Agent_Runtime_System_v1.md.

These informed real changes already applied to the runtime system —
kept here as the historical record of that reasoning, not just
reference material.
